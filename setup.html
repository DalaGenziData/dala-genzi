Connect the Google Sheet

  1. On a computer, open sheets.new. Name the sheet Dala Genzi Data.
  2. Click Extensions, then Apps Script.
  3. Delete everything in the code box. Press the Copy code button below, then paste it into the code box. Press Ctrl+S.
  4. Click Deploy, then New deployment. Click the gear icon and choose Web app.
  5. Set Execute as to Me, and Who has access to Anyone (not "Anyone with Google account"). Click Deploy.
  6. Click Authorize access and choose your Gmail. If it warns you, click Advanced, then Go to project, then Allow.
  7. Copy the Web app link that ends in /exec and send it to Claude.
